# ⚡ Quick Start Guide

## 🚀 Get Running in 2 Minutes

### Step 1: Install Dependencies

```bash
npm install
```

_(This should take 1-2 minutes)_

### Step 2: Start the App

```bash
npm start
```

### Step 3: Open on Device

Choose one:

**Android Emulator:**

- Press `a` in the terminal
- Wait for app to open

**iOS Simulator:**

- Press `i` in the terminal
- Wait for app to open

**Your Phone:**

- Scan the QR code with Expo Go app
- App opens on your phone

## 🎨 If You Want to Customize

### Change Colors:

1. Open `constants/theme.js`
2. Find the `colors` object
3. Change hex values
4. Save - app updates instantly!

Example:

```javascript
primary: '#YOUR_COLOR_HERE',
```

### Add New Screen:

1. Create file in `screens/` folder
2. Copy structure from another screen
3. Add route in `App.js`
4. Add feature card in `HomeScreen.js`

## ❓ Quick Troubleshooting

**App won't start?**

```bash
npx expo start -c  # Clear cache
```

**Can't find emulator?**

- Open Android Studio or Xcode first
- Start emulator from there
- Then run `npm start` again

**See red errors?**

- Usually just warnings
- Reload app with `r` key
- Should clear
