## 🛠️ If You Want to Customize

### Change Colors:

1. Open `constants/theme.js`
2. Edit the colors object
3. Save
4. App updates instantly!

### Add New Topic:

1. Create `screens/YourScreen.js`
2. Add route in `App.js`
3. Add card to `HomeScreen.js`

### Change Styling:

- Edit theme.js (centralized)
- All screens use the same tokens

## 📞 If Something Goes Wrong

**App won't start?**

```bash

```

**See errors?**

- Usually just warnings
- Press `r` to reload
- Should clear

**Can't see emulator?**

- Open Android Studio/Xcode first
- Start emulator from there
